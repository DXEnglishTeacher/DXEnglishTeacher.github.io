ままるっと教室無料版
⚠ 無料版（ブラウザ版）をお使いの先生へ 名前は番号や名字だけでも使えます。データはこの端末のブラウザの中だけに保存されますが、共用のパソコンや個人のスマホで使ったあとは「データを消す」を押してください。個人情報の扱いは、勤務校のルールを確認してからお使いください。

Excelから名簿を貼り付け

Excelで「番号・氏名・ふりがな・性別」の列を選んでコピーし、下に貼り付けてください。
氏名だけでも大丈夫です。1行目が見出しなら自動で読みとばします。

ほかの先生と席を共有

かんたんな使い方

  1. 名簿　Excelの名簿をコピーして貼り付けます。まずは「サンプルで試す」で動きを確認できます。視力・配慮・リーダーなどは、必要なものだけ入れればOKです。
  2. 教室　列の数と班の形を決めます。使わない席はタップで消せます。
  3. 条件　近くにしたくない2人などを登録します（なくても大丈夫です）。
  4. 席替え　「席替えする」を押すだけ。気に入らなければもう一度押します。席をタップして入れ替えもできます。決まったら「この席で決定」。
  5. 指名・班　授業でランダムに当てたり、その場で班をつくったりできます。

🔒 名前などのデータは、この端末のブラウザの中だけに保存され、インターネットには送られません。
💾 ときどき「保存ファイルに書き出す」でバックアップをとってください。
🔑 教科担当の先生は、担任の先生から「共有コード」をもらうと、名簿や席を入力しなくても使えます。
